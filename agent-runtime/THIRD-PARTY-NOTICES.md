## Packages that bundle other code

Several Python wheels carry native libraries that other people wrote, and the image you build contains them:

- pypdfium2: a PDFium binary with FreeType, ICU, libjpeg-turbo, libpng, OpenJPEG and zlib.
- numpy, in its Linux wheels: OpenBLAS (BSD-3-Clause), libgfortran (GPL-3.0-or-later WITH GCC-exception-3.1) and libquadmath (LGPL-2.1-or-later).
- Pillow, lxml, cryptography and onnxruntime: their own native libraries.

The licence column below gives each package's own licence. Each wheel holds the licence texts of what it carries in its `.dist-info` folder.

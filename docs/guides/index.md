# Guides

Step-by-step tutorials and walkthroughs for using the IniaAi Platform.

## Available Guides

### [Quickstart](../getting-started/quickstart.md)
Start the platform with the one-command Docker stack, run the sample workflows, and check a report whose figures link to their pages.


### [End-to-End Guides](end-to-end/index.md)
Numbered journeys from nothing to a verified result, by goal: build a workflow, integrate against the API, debug a run.

### [Workflows](workflows/index.md)
Learn how to create workflows, use the workflow editor, and configure document classes.

### [Reading a Report](workflows/reading-a-report.md)
Read a finished report in IniaAi.Web — run-status labels, following a citation back to its source page, and downloading or exporting the result.

### [Block Catalog](blocks/index.md)
Browse every block type available to workflow authors — the full block reference plus the Core, AI, Data, Control, and Utility block catalogs.

### [Page Overview Prompts](page-overview-prompts.md)
Set the prompts a workflow summarises document pages with, on the editor's Document Classes tab, and clear the warning for blocks that search pages without overviews.

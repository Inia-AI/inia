## Files in this repository that Inia did not write

### Apache ECharts, ZRender and parts of d3, in the chart bundle

- Files: `chart-builder/charts.global.js`, which `npm run build:chart-builder` builds from the app's chart code and the `echarts` package.
- Versions: the first lines of `charts.global.js` name the ECharts and ZRender versions it embeds, the same as the package list below.
- Upstream: <https://github.com/apache/echarts>, <https://github.com/ecomfe/zrender>, <https://github.com/d3/d3>
- Licences: Apache-2.0 (ECharts), BSD-3-Clause (ZRender, d3). The texts and the ECharts notice are in the same folder: `LICENSE-echarts`, `NOTICE-echarts`, `LICENSE-zrender` and `LICENSE-d3`.

### shadcn-vue components

- Files: `src/components/ui/`, components generated with the shadcn-vue CLI from the settings in `components.json`.
- Upstream: <https://github.com/unovue/shadcn-vue>
- Licence: MIT. The text is in the same folder: `LICENSE-shadcn-vue`.

- Terms: its author released it into the public domain, without restrictions.
